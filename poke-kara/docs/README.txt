Квест #132 + NPC #9007 (Марек, Покемаркет)

Что внутри:
- do/Npc/9007.php  — NPC продавца + квест #132.
- do/Npc/9007.png  — портрет NPC.
- do/Npc/lib/NpcBattle.php — исправленная библиотека старта боя.
- do/Npc/lib/NpcKit.php   — исправленная библиотека (совместимость с Work::$sql).
- sql/quest_132_marek_vendor.sql — SQL (идемпотентный) для квеста/NPC/ассортимента.

Почему бой не запускался:
- В npc_modern_patch_v4 в /do/Npc/lib/NpcBattle.php была ошибка: bind_param имел строку типов на 10 параметров при передаче 9 переменных.
  На части серверов это давало battleId=0, а на части — HTTP 500 (в зависимости от обработчика ошибок PHP).
- В этом пакете NpcBattle.php исправлен (корректные строки типов) и добавлен fallback на Work::$sql,
  если global $mysqli отсутствует.

Изменения в шаге 1 квеста:
- Раньше требовались 3 априкорна.
- Теперь требуется 1 любая деталь (в дропе):
  - 73: Осколок громового камня (электрические)
  - 74: Осколок водного камня (водные)
  - 75: Осколок лиственного камня (травяные)
  Альтернатива: оплатить 3000 генкаров.

Установка:
1) Файлы
   - Скопируйте do/Npc/9007.php в /do/Npc/9007.php
   - Скопируйте do/Npc/9007.png в /do/Npc/9007.png
   - Скопируйте do/Npc/lib/NpcBattle.php в /do/Npc/lib/NpcBattle.php (с заменой)
   - Скопируйте do/Npc/lib/NpcKit.php   в /do/Npc/lib/NpcKit.php   (с заменой)

2) База данных
   - Выполните sql/quest_132_marek_vendor.sql

Проверка:
- Зайдите к Мареку -> Проверка -> Финальный шаг -> Начать бой.
- Диалог должен закрыться и игрок должен попасть в бой.

Если все равно не стартует:
- Проверьте, что в проекте есть класс Info и метод Info::_userInfoBattle().
- Проверьте, что в базе есть таблицы battle, battle_log и поля users.status/status_id.
- Смотрите PHP error log: там будет точная причина (ошибка SQL/прав доступа/несоответствие схемы).
